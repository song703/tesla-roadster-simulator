Tesla Roadster Programming Simulator

Students in Secondary 2–3 write a short program. The car follows the circuit. Lesson 4 is the marked task. The loop ramp comes after, as an optional extension.

Group presentation · November 2026

Sequence. Repeat. If. Not affiliated with Tesla, Inc.

The task

They program the car. They do not drive it.

Start → Add commands → Preview → Run

1The class

  • Hong Kong students in Secondary 2–3, about 13–15.
  • Four lessons, about 40 minutes each.
  • One shared browser. Nothing to install.
  • Preview the path, then run the program.

2The panel

  • Every program has Start and Stop.
  • Set Max Speed, Follow Track, Repeat, If, Brake.
  • Set Max Speed is in m/s.
  • The strip shows speed, distance, time, and lap.

3Two sites

  • The circuit is Lessons 2 to 4.
  • Checks are prompts, not the grade.
  • The loop ramp is a second site.
  • Launch is optional and not marked.

Before the car moves

Each lesson adds one command.

1Paper

  • Without computers, students work in pairs.
  • They write six to ten lines and swap.
  • “Go properly” is not a program command.
  • Rewrite it as a number plus an action.

2One lap

  • Start. Set Max Speed 16. Follow Track. Stop.
  • 16 means 16 m/s.
  • One lap, still on the track, past 100 m.
  • Point to the line that set the speed.

3Repeat

  • Repeat 2 times { Follow Track } at 20 m/s.
  • Pasting the lap twice is a weaker program.
  • The check passes only if Repeat is included.
  • The lap count must reach 2.

4If

  • If lap ≥ 1, set the target to 12 m/s.
  • Then Brake 6 and Stop.
  • The car must finish under 2 m/s.
  • This program, two readings, and one sentence are the grade.

  • 3. Follow the track.

Launch on the loop ramp.

What the run is doing

  • This is a different type of run.
  • Start, Launch, Record Data, and Stop.
  • Launch sends the car up the ramp, around the 170° loop, and through the landing.
  • Thrusters help the car level itself.
  • The result shows height in metres, peak g, and kilograms of air used.
  • Holding W drives the car by hand. That is not the task.

Why it stays optional

  • An extension after Lesson 4, not the core task.
  • The question: is the speed high enough to complete the loop?
  • Launch is not graded.
  • The Lesson 4 circuit program remains the focus.

After both runs

Remember three things from Lesson 4.

The program

  • An If condition must eventually become true.
  • “If lap ≥ 1” works after the first lap.
  • “If lap = 2” fails if the run never reaches lap 2.
  • The program must also include Start and Stop.

Two readings

  • Record the speed during lap 1 and lap 2.
  • In the sample, the target speeds are 24 m/s and 12 m/s.
  • Braking alone does not make the program pass.

One sentence

  • “Lap became 1, then max speed changed to 12.”
  • The sentence describes what happened.
  • The three on-screen checks are prompts for the teacher, not extra commands.
