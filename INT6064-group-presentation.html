tesla-roadster-simulator

Secondary 2–3 write a short program. The car follows it. First the circuit, where Lesson 4 is marked. Then the curl ramp, which is optional.

Sequence. Repeat. If. Not affiliated with Tesla, Inc.

The task

They program the car. They do not drive it.

The class

Hong Kong Secondary 2–3, about 13–15. Four lessons of about 40 minutes. Pairs share one browser. Nothing to install. Keyboard driving is turned off for the marked work. Path Preview, then Run.

The panel

Every program opens with Start and ends with Stop. The commands they need are Set Max Speed, Follow Track, Repeat, If, and Brake. Set Max Speed is in m/s. The strip under the stage reads speed, acceleration, distance, time, and lap from the same run.

Two sites

Circuit is Lessons 2 to 4. The in-app checks are prompts: one lap on track, two laps with Repeat, and an If that leaves the car nearly stopped. Curl ramp is a different site. Launch is the only extra command, and it is not marked.

Before the car moves

Each lesson adds one command.

1 · Paper

No computer. Pairs write six to ten lines and swap. The other pair walks a taped rectangle and does only what is written. “Go properly” fails. The rewrite is a number plus an action.

2 · One lap

Start, Set Max Speed 16, Follow Track, Stop. 16 is 16 m/s. The check wants lap at least 1, still on track, and more than 100 m. They point at the line that set the speed.

3 · Repeat

Repeat 2 times around Follow Track, at 20 m/s. Two pasted Follow Track lines also finish two laps. The check passes only when Repeat is in the program and lap is at least 2.

4 · If

Inside that Repeat: If lap >= 1 then Set Max Speed 12, then Brake 6. The check wants an If and a car slower than 2 m/s. They write both speeds and one sentence. That is the grade.

This is the Lesson 4 program.

What Run is doing

Set Max Speed 24. Repeat 2 times: Follow Track, then If lap >= 1 then Set Max Speed 12. Brake 6. Stop. Lap 1 holds 24 m/s. When lap becomes 1, the cap falls to 12. Brake brings the car under 2 m/s.

What to read

Speed (m/s), distance (m), time (s), and lap, on the strip. The green checks are prompts. A copied sample with no one able to point at the If does not count. Stop inside the Repeat would end the run on lap 1.

Launch on the curl ramp.

What Run is doing

A different site. Start, Launch, Record Data, Stop. Launch sends the car up the runway, around the 170° curl on suction, upside down, then the thrusters roll it level and it lands. The result line is height in metres, peak g, and kilograms of air. Holding W drives it by hand. That is not the task.

Why it stays optional

Finished pairs only, in the last minutes of Lesson 4. The question is what happens if max speed is too low to climb. Record Data is not required. Follow Track already hides steering, and this stunt hides it further. The mark is still the circuit program.

After both runs

Keep three things from Lesson 4.

The program

An If that reads lap or speed, placed so it can become true. If lap = 2 fails because lap 2 does not exist yet. If lap >= 1 after the first Follow Track is the line they can point at. Missing Start or Stop is rejected before the car moves.

Two readings

Speed during lap 1 and speed during lap 2, copied from the strip. In the sample those are 24 m/s, then 12 m/s. Brake with no If can stop the car and still does not pass.

One sentence

“Lap became 1, then max speed changed to 12.” The three on-screen checks are prompts for the teacher. The sentence is the student checking the run against the program.
