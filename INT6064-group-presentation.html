tesla-roadster-simulator

A safe test lap for Secondary 2–3. Students write the instructions. One idea is added each lesson, then you see it run twice: the laps, then the ramp.

Sequence. Repeat. If. Not affiliated with Tesla, Inc.

The task

One number becomes a motion.

Who it is for

Hong Kong Secondary 2–3, about 13–15. Four lessons, about 40 minutes. Pairs share one browser tab and install nothing. They do not steer. They send the car around the circuit and slow it down when a rule is met.

Why not Scratch or Python

Scratch already taught them sequence, but ten steps is not metres per second. Python is the next module, when the same brief becomes a table. Here they type Start, Repeat, and If. There is no eval, and a run is capped.

What the two runs show

Both pages use the same rule. Set a speed, run the program, read the strip. The circuit is the required work. The ramp is that rule on a jump, for pairs who finish early. It is not a fifth lesson.

Before the car moves

Four lessons. One new line each time.

1 · Paper

No computer. Pairs write the lap, then swap. The other pair walks only what is written. “Go properly” fails. One vague line is rewritten as a number plus an action.

2 · Sequence

Start, Set Max Speed, Follow Track, Stop. A broken program is shown first. They change only the speed and say what the strip did.

3 · Repeat

The same lap, counted. Pasting Follow Track twice is the same motion and a worse algorithm, because a change must be made in two places.

4 · If

After lap 1, the cap falls. They keep the program, two readings, and one sentence. That is the grade. The banner in the app is only a prompt.

Lessons 2 and 3, on the circuit.

The program on screen

Set Max Speed 20, then Repeat 2 times Follow Track. 20 is 20 m/s. Lesson 2 was that speed on one lap. Lesson 3 counts the lap instead of pasting it. Lesson 4, next, drops the second lap to 12.

Read the strip

Time, speed, and distance belong to this run. Ask which line chose 20. A copied sample that happens to pass is not the mark.

The same rule, on the ramp.

Still one number

The last page set 20 m/s for a lap. This page uses Launch, the cold-gas push, and the speed has to be enough for the jump. Start, Launch, Record Data, Stop. The strip is still how they know it worked.

Still not lesson 5

Pairs who finish the four lessons can try it. The stunt is easy to overuse, because it hides the algorithm. The grade stays on the circuit: program, two readings, one sentence.

After both runs

Lesson 4 is the mark.

Program, readings, sentence

An If tied to lap or speed, the two speeds from the strip, and one sentence: “Lap became 1, then max speed changed to 12.” The banner in the app is a prompt. A copied sample does not count.

The mistake we expect

If lap = 2 names a lap that does not exist yet. Use lap >= 1 after the first Follow Track. A missing Start or Stop is rejected before the car moves. Faster is not the goal. Lesson 4 lowers the cap.

What the ramp is not

It uses the same rule and it is not assessed. Follow Track already hides the steering, so the jump can look like success without an algorithm. The required work stays on the laps.
