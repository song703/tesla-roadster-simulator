tesla-roadster-simulator

A safe test lap. Four lessons for Secondary 2–3. Students write the instructions. The next pages are the program itself.

Sequence. Repeat. If. Not affiliated with Tesla, Inc.

What this project is

Students write the lap. They do not drive it.

The problem

A test driver must finish the laps, stay in lane, and slow down when a rule is met. Hong Kong Secondary 2–3, about 13–15. Four lessons, about 40 minutes each. Pairs share one browser tab. They install nothing.

The STEM

Mathematics: speed is distance over time, and the strip prints both. Physics: Set Max Speed 16 is 16 m/s, and Brake changes that target. A number in the program becomes motion on the circuit.

The language

Start and Stop frame every program. Repeat is a counted loop. If reads speed, lap, and distance from the car. There is no eval. Foo is refused before the car moves. A copied sample is not the mark.

Run the laps.

What is running

Set Max Speed 20, then Repeat 2 times Follow Track. 20 is 20 m/s. Lessons 2 to 4 all stay on this circuit. The car is the evidence. The program is the work.

What to point at

The data strip, not the bodywork. Pasting the lap twice is the same motion and a worse algorithm. On the next lap an If can drop the cap to 12. A copied sample is not the mark.

What is running

Start, Launch, Record Data, Stop. Launch is the cold-gas push up the curl ramp. The speed they set has to be enough for the jump. Same rule as the circuit: a number becomes a motion.

What to say

Early finishers only. Easy to overuse, because the stunt hides the algorithm. It is not a fifth lesson. The required work stays on the laps.

Between Scratch and Python.

Scratch

Right for upper primary. This class has already met sequence in blocks. A sprite that moves ten steps does not make metres per second visible.

This

They type a line instead of dragging a block. That is the step before Python, but they never write a general script. Loops, length, and run time are capped.

Python

Better when the goal is a table or a graph. This tool will not sit a Python exam, and it does not teach files or a micro:bit. Next module: the same brief as a loop.

The four lessons

One new idea each time.

1 · Paper

No computer. Watch one lap, then write six to ten lines. The other pair walks a taped rectangle and does only what is written. “Go properly” fails. The exit ticket is one line rewritten as a number plus an action.

2 · Sequence

Start, Set Max Speed, Follow Track, Stop. Show a broken program first. Pairs change only the speed and say what the strip did: higher cap, still one lap.

3 · Repeat

One lap, named and counted. Pasting Follow Track twice is the same motion and a worse algorithm, because a change must be made in two places. Predict Repeat 3 before they run it.

4 · If

After the first lap, go slower. They write both speeds and one sentence. That work is the grade. The banner in the app is a prompt, not the mark.

In the room

What we say when it goes wrong.

No Start or Stop

The editor rejects it before the car moves. It is not a Scratch stack of loose blocks.

If lap = 2

They wrote the ending they want. Lap 2 does not exist yet. Use lap >= 1 after the first Follow Track.

Faster feels safer

The advanced task lowers the cap on purpose. Follow Track hides steering. The ramp is not lesson 5.

The grade

Lesson 4 only. Three pieces.

The program

An If tied to lap or speed, and the motion actually changes. They can point at the line. A passed banner from a copied sample does not count.

Two readings

Speed on lap 1 and speed on lap 2, taken from the strip. The in-app check is a prompt for the teacher, not the mark.

One sentence

“Lap became 1, then max speed changed to 12.” That is computational thinking checked against the physics, not a longer program.
