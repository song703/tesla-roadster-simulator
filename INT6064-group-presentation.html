Tesla Roadster Programming Simulator

Five programs from the Tutorial menu. One lap. Two laps. A slower second lap. A square. Then the car takes off.

Group TUFF · November 2026 · Not affiliated with Tesla, Inc.

From the Tutorial

Build a program. Preview it. Then run it.

Start → Add commands → Path Preview → Run

1Add a block

  • Pick a command on the right.
  • It inserts at the cursor.
  • The old lines stay.
  • Type the number, then press the block.

2Run it

  • Path Preview draws the route.
  • Run drives that route.
  • Reset returns the car to the start.
  • Every program has Start and Stop.

3Two sites

  • The circuit uses Follow Track, Turn, and Drive.
  • The curl ramp uses Launch.
  • The next pages are the five programs.
  • Load them from the sample menu, in this order.

Beginner

One lap. Stay in the lane.

What it is

  • The Tutorial calls this “Reach the finish line.”
  • Set a maximum speed, then follow the track once.
  • The goal is one lap without leaving the lane.

The program

  • Start
  • Set Max Speed 16
  • Follow Track
  • Stop

What 16 means

  • 16 is 16 metres per second.
  • Point at the line that chose it.
  • A copied sample is not the mark.

Intermediate

Two laps, with Repeat.

What it is

  • The Tutorial calls this “Two clean laps.”
  • The same lap runs twice because it is counted.
  • The goal is Repeat, and every lap stays on the track.

The program

  • Start
  • Set Max Speed 20
  • Repeat 2 times { Follow Track }
  • Stop

What does not count

  • Pasting Follow Track twice can look the same.
  • A later change must then be made twice.
  • Stop inside the braces ends the run on lap 1.

Advanced

Slow down for lap two.

What it is

  • The Tutorial calls this “Brake on a condition.”
  • Lap 1 stays at 24 m/s.
  • When lap becomes 1, the target falls to 12 m/s.

The program

  • Set Max Speed 24.
  • Repeat 2 times { Follow Track }.
  • If lap ≥ 1, set the target to 12.
  • Then Brake 6 and Stop.

What to read

  • Speed on lap 1 and speed on lap 2.
  • The targets are 24 m/s, then 12 m/s.
  • One sentence: lap became 1, then the speed changed.

Square

Four corners. No centreline.

What it is

  • This sample does not use Follow Track.
  • The car draws a square with Drive and Turn.
  • A square is a different route from one lap of the circuit.

The program

  • Drive Forward 15.
  • Turn Left 90.
  • Those two lines, four times.
  • Then Stop.

Why it is here

  • The Tutorial allows Turn and Drive on the circuit.
  • Follow Track hides the steering.
  • This program makes the turn visible.
